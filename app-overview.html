🧩 React Components

Five reusable components power the dashboard and demo views.

💬 ChatAssistant

Floating chat widget that streams AI responses via SSE. Supports member targeting, suggested prompts, and auto-scrolling conversation history.

👤 FamilyMemberCard

Profile card showing name, age, life stage emoji, wellness philosophy, dosha (if Ayurvedic), and personal goals.

📅 MealPlanGrid

7-column day grid with expandable MealCard sub-components. Each card shows timing, cuisine type, ingredient list, step-by-step instructions, and per-member "Why it works" explanations.

🛒 GroceryList

Categorized (produce / protein / dairy / grains / pantry / frozen) shopping checklist. Includes quality flags, money-saving tips, member tags, and a live budget progress bar.

💊 SupplementPanel

Accordion per family member with expandable supplement recommendations — dosage, timing, approach (Ayurvedic / TCM / Western), contraindications, and brand suggestions. Only visible for members who opted in.

✨ Key Features

What the app actually does for families today.

🧙 Personalized Onboarding

Multi-step wizard capturing 15+ data points per member — demographics, dietary style, wellness philosophy, goals, allergies, cuisine preferences, health conditions, and supplement opt-in. Ayurvedic philosophy unlocks a dosha selector. Requires disclaimer acceptance before submission.

📅 AI Meal Planning (7-day)

Claude Sonnet generates a full week of meals (breakfast, lunch, dinner, snacks) personalized for every family member simultaneously. Each meal includes per-member "Why it works" explanations. Users can regenerate the whole plan or swap individual meals.

🛒 Smart Grocery Lists

Automatically synthesized from the meal plan. AI consolidates ingredients across all 7 days, assigns categories (produce / protein / dairy / grains / pantry / frozen), adds quality flags (organic/local), member tags, and money-saving tips. Live budget bar turns red if over budget.

💊 Supplement Guidance

Per-member personalized recommendations respecting their wellness philosophy — Ayurvedic herbs, TCM tonics, or Western nutraceuticals. Each supplement includes dosage, timing, form, contraindications, and brand suggestions. Opt-in only.

💬 Streaming Chat Assistant

Floating chat widget with real-time SSE streaming. Context-aware: knows the family profile and can target specific members. Suggested prompts help new users get started. Full conversation history passed to Claude on each turn.

🎯 Investor Demo Mode

Pre-loaded Rivera family with all features visible (meals, grocery, supplements, live chat) without requiring onboarding. Designed for product demos and investor presentations.

🏗️ Architecture Overview

How the pieces connect.

🖥️ Next.js 14 Frontend

TypeScript, Tailwind CSS, Lucide icons. Client-side state via React hooks. SSE streaming for chat. Responsive grid layouts.

⇄

⚡ FastAPI Backend

Async/await throughout. Pydantic models for validation. /api/chat proxied through Next.js API route for SSE support.

🤖 WellnessAgent (Claude Sonnet 4.6)

Core AI engine with prompt caching. Generates meal plans, grocery lists, supplement guides, and chat responses. Tool-use for structured output.

⇄

🗄️ Supabase PostgreSQL

asyncpg driver. Families stored as single data blobs + members indexed separately for quick lookups. Cascade deletes.

🔭 Phoenix Arize Observability

OpenInference tracing on every request. Custom span attributes: family.id, family.member_id, wellness.request_type, llm.model.

⇄

🐳 Docker Compose

Containerized frontend, backend, and observability stack. start.sh / stop.sh for convenience. Langflow container for visual agent editing.
