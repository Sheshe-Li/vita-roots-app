Live AI · Streaming

Try the live wellness assistant

The chat in the bottom-right calls your local FastAPI backend, which streams Claude Sonnet 4.6 responses with full Phoenix tracing on every call.

Before chatting · 3-step setup

  1. Start the backend: cd backend && uvicorn main:app --reload --port 8000 (or docker-compose up).
  2. Make sure ANTHROPIC_API_KEY is set in backend/.env.
  3. Click Connect & Seed Rivera Family in the chat header. The chat endpoint will 404 until the demo family exists in your database.

CORS note: if you opened this file directly with a file:// URL, the browser will block requests to localhost:8000. Serve this file from any localhost port (e.g. python -m http.server 3000) — the backend already allows localhost:3000. For other ports, add the origin to CORSMiddleware in backend/main.py.

QA & Observability

Every recommendation is auditable

For a health-adjacent product, trust is the moat. Phoenix Arize captures every Anthropic call with custom attributes — we can audit what the AI said, to whom, when, and why.

Span attributeCaptured value
family.idUUID of the family
family.member_idUUID of the affected member (when scoped)
wellness.request_typemeal_plan · grocery · supplement · chat
llm.modelclaude-sonnet-4-6
chat.message_length / chat.history_lengthFor chat spans
meal_plan.week_start / grocery.budgetPer-request scoping

Source: backend/observability.py + backend/agent.py · spans wrapped via OpenInference's AnthropicInstrumentor.

  • OTLP exporter · OpenTelemetry → Phoenix at http://localhost:6006/v1/traces (or Phoenix Cloud with PHOENIX_API_KEY).
  • Initialized first · init_observability() runs at the very top of main.py, before the Anthropic SDK is imported, so 100% of calls are wrapped.
  • Prompt caching visible · the system block is cached (ephemeral). Cache hits reduce per-request cost ~65% — and the savings are visible in Phoenix.
  • Eval-ready · Phoenix supports automated quality, safety, and accuracy evals. Evals are wired but not yet running on a schedule — see Production Audit.
  • Open Phoenix UI · localhost:6006 while the docker stack is up.
Honest Assessment

What's production-ready · and what isn't

This is a working capstone product, not a mockup. But before paying customers and investor capital, here's the honest gap list — sourced directly from the code.

The Ask

Why now · why us · what we need

Families are more health-conscious than ever, but the tools they have are generic. We're the first product to take per-member personalization seriously — backed by the most capable consumer LLM, on a fully-traced stack.

Market

Whole-family wellness is unsolved

MyFitnessPal tracks one person's calories. Google gives one-size-fits-all results. Nobody serves each member of a household with their own philosophy and constraints.

Monetization

Freemium subscription

Free: 1 member, 1 plan/month. Family: $14.99/mo, up to 8 members. Premium: $24.99/mo with Instacart + Apple Health. B2B: white-label for functional medicine practices.

Moat

Per-member, multi-philosophy

Ayurvedic, TCM, and Western integrative — same family, same week, three different lenses on the same meal. Defensible because it requires nuanced reasoning few teams can prompt-engineer.

Cost

~65% per-request savings via prompt caching

The system prompt + family context are cached as ephemeral. Subsequent calls within the cache window don't re-bill the cached tokens — material to unit economics at scale.

Trust

Health-grade observability from day one

Every AI response is captured in Phoenix with family/member/request-type attributes. We can audit, eval, and detect drift toward medical claims — critical when scaling a wellness product.

The Ask

Pre-seed for closed beta + compliance

500 families, practitioner partnerships, and the compliance work surfaced in the audit above (auth, rate limits, COPPA flow, content moderation). 6-month runway to revenue traction.
